# AI Governance Guide

See src/governance/README.md for the complete enterprise governance framework covering model cards, data documentation, compliance frameworks (GDPR, EU AI Act, HIPAA, SOC 2), audit trails, access control, and incident response.

## The Enterprise Governance Stack

```
LEGAL & COMPLIANCE
├── Regulatory frameworks (GDPR, EU AI Act, HIPAA, SOC 2, industry-specific)
├── Terms of service and user consent
└── Data protection agreements

RISK MANAGEMENT
├── Risk assessments (per deployment)
├── Threat models
└── Incident response plans

TECHNICAL CONTROLS
├── Access control (RBAC, MFA, break-glass)
├── Audit logging (immutable, searchable)
├── Data protection (encryption, retention, deletion)
└── Model versioning and rollback

DOCUMENTATION
├── Model cards
├── Data documentation
├── Runbooks
└── Compliance reports

PROCESS
├── Pre-deployment sign-offs
├── Quarterly compliance reviews
├── Incident response drills
└── Continuous monitoring
```
